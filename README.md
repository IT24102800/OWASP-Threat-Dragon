# OWASP-Threat-Dragon

A university Online Student Portal where students sign in to view personal 
information and examination results, and lecturers sign in to update 
examination results. The Web Application sends credentials to an 
Authentication Service, reads and updates records in a Student Database, 
and uses an External Email Service to send password-reset emails. The 
portal is accessed through the Internet. The database contains sensitive 
personal and academic information.
